# カードデータ生成プロンプト（CSV → cards.json）

使い方：以下の「プロンプト本文」をそのままAIに貼り、フォームの回答CSVを添付する（またはプロンプトの末尾に貼り付ける）。出力されたJSONを `data/cards.json` に保存する（`data/` はGitに入れない）。

---

## プロンプト本文

あなたは、ゼミの合宿で使うトレーディングカードの編集者です。添付したCSVは、ゼミ生が事前フォームに答えた回答です。1行が1人分です。これを、カードに印刷するためのJSONに変換してください。

### カードの目的

このカードは「インテリジェントなチームを作れ！」というゲームで使います。プレイヤーは2分間で約15枚の手札を読み、お題に合う3人のチームを選びます。そのため、**その人が何を得意としていて、誰と組むと強いのかが、一瞬で読み取れること**が何より大事です。

### 入力のCSVの列

`同意`, `ニックネーム`, `一言キャッチコピー`, `チームでの役割`, `助けられるジャンル`, `具体的に助けられること`, `自分の強み`, `オリジナル技`, `相性◎`, `好きな色`, `趣味・ハマっていること`, `写真`, `イラストに入れてほしいモチーフ`

### 出力の形式

JSONの配列だけを出力してください。前置きや説明は不要です。

```json
[
  {
    "id": "001",
    "name": "グラフの魔術師",
    "role": "参謀",
    "catch": "とりあえず可視化してから考えよう",
    "tags": ["統計", "デザイン"],
    "strengths": ["データの整理", "図解", "粘り強さ"],
    "move": { "name": "一目瞭然プロット", "effect": "散らかったデータを一枚の図にまとめ、議論を3分で収束させる。" },
    "aisho": "アイデアを次々出す人と組むと、それを形にして輝く",
    "help": "アンケート集計、グラフの見せ方",
    "color": "青",
    "has_photo": false,
    "art_emoji": "📊",
    "illustration_prompt": "A friendly analyst character surrounded by colorful floating charts ...",
    "generated_fields": ["catch"],
    "review_flags": []
  }
]
```

### 各項目のルール

| キー | ルール |
|---|---|
| `id` | CSVの行の順に `001` から振る |
| `name` | `ニックネーム` をそのまま使う。12字を超える場合だけ短くし、`review_flags` に記録する |
| `role` | `チームでの役割` をそのまま使う |
| `catch` | `一言キャッチコピー` を20字以内で。空欄なら、強みと趣味からその人らしい一言を作る |
| `tags` | `助けられるジャンル` を、統計／プログラミング／デザイン／英語／文章添削／プレゼン／企画／リサーチ／動画編集 から最大3つ。「その他」は `具体的に助けられること` を読んで最も近いものに置き換え、どれにも当てはまらなければ省く |
| `strengths` | `自分の強み` を2〜3個、各10字以内に整える |
| `move` | `オリジナル技` があれば、本人の技の名前を尊重し（12字以内）、効果を40字以内に整える。空欄なら、強みをもとに遊び心のある技を作る |
| `aisho` | `相性◎` を35字以内で「〜な人と組むと、〜」の形に整える |
| `help` | `具体的に助けられること` を30字以内で |
| `color` | `好きな色` をそのまま使う |
| `has_photo` | `写真` が空でなければ `true` |
| `art_emoji` | タグや強みを表す絵文字を1つ。イラストが間に合わない場合の代用 |
| `illustration_prompt` | `has_photo` が `false` の人だけ、英語でイラスト生成用の指示を書く（下記参照）。`true` の人は空文字 |
| `generated_fields` | 本人の回答ではなくAIが作った項目のキーを列挙する |
| `review_flags` | 人が確認すべき点を日本語で列挙する |

### 守ってほしいこと

- **本人の言葉をできるだけ残す。** 文字数を収めるための言い換えは最小限にし、勝手に盛らない
- **回答に書かれていない事実を作らない。** 経歴、所属、実績などを推測で足さない
- `相性◎` に**特定の人の名前**が書かれていたら、その人の特徴に言い換えたうえで `review_flags` に「相性に名前が含まれていたため言い換えた」と記録する
- `同意` にチェックがない行は出力に含めず、最後にその行番号を `review_flags` を持つ別オブジェクト `{"id":"SKIPPED","review_flags":[...]}` として出力する
- 悪口、からかい、他人を下げる表現は使わない。本人の自虐が強すぎる場合は、やわらげたうえで `review_flags` に記録する
- `illustration_prompt` は、写真がない人の雰囲気を表す明るいアニメ調のキャラクターを描写する。顔立ちや人種、性別を推測して書かない。趣味やモチーフ、タグに関する小物を入れる。文字は入れない。末尾に必ず「absolutely no text, no letters」を付ける
