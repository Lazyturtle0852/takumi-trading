# ルール仕様（v0.4）

## 全体（60分）

| 時刻 | 内容 |
|---|---|
| 0:00 | ルール説明。新規生7人でじゃんけんをし、勝った1人がシード |
| 0:05 | 1回戦（3試合）。シードの人は観戦 |
| 0:29 | 準決勝（2試合）。1回戦の勝者3人＋シード |
| 0:45 | 決勝（ルールは他の試合と同じ） |
| 0:53 | 優勝者の表彰。全員が「今日初めて知った誰かの強み」を1つ言う |

1試合は約6分。入れ替えを含めて8分の枠で回す。押したら決勝以外のプレゼンを30秒に短縮する。

   ├─ 第1試合 ─┐

全試合を全員で観戦する。

## 1試合の流れ

1. **お題を引く（30秒）**: お題カード（またはルール説明ページのガチャ）をランダムに1枚引き、読み上げる
2. **山札を半分に分ける（30秒）**: 全員分のカードを1つの山札にまとめてシャッフルし、半分ずつ2人に配る
3. **チームを作る（2分）**: 自分の手札だけから3枚を選び、チーム名を決める
4. **プレゼン（45秒×2）**: 選んだ3枚をホワイトボードにマグネットで貼る。選ばれた3人はその場で前に立つ。「チーム名」「誰が何をするか」「なぜこの3人ならお題を達成できるか」を語る。本人からの一言コメントも可
5. **判定（1分）**: 観戦者全員が、より「インテリジェントなチーム」だと思った方に挙手で1票。相性ボーナスを加え、合計が多い方が勝ち上がる

## 相性ボーナス

- 各カードには、本人が書いた「🤝 相性◎：こんな人と一緒だとパフォーマンスが上がる」が載っている
- プレゼンで「AさんとBさんは相性◎、なぜならBさんは〇〇だから」と根拠を添えて主張する
- カードの本人が会場で「OK！」を出せば成立し、1つにつき＋2票
- 本人が不在のとき、または意見が割れたときは、たくみさんが最終判断する
- シナジー表のような覚えるルールは作らない
