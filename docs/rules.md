# ルール仕様（v0.6）

## 全体

チームA〜Dの4チーム対抗。アクティビティ3種類と料理の合計点で優勝チームを決める（新規生7人のソロ・トーナメント案は廃止）。

| 種類 | ゲーム | 状態 |
|---|---|---|
| 推論 | 目的ズレ人狼 | 確定 |
| 注意力 | 妨害ジェスチャー | 確定 |
| 資源 | インテリジェントなチームを作れ！（カードゲーム） | 既存 |

### アクティビティ（計90分）

| 時刻 | 内容 | 内訳 |
|---|---|---|
| 0:00〜0:10 | 全体説明 | チーム確認・得点のつけ方 |
| 0:10〜0:35 | ① 推論：目的ズレ人狼 | 説明3分・ゲーム18分（やり方は未決）・振り返り4分 |
| 0:35〜1:00 | ② 注意力：妨害ジェスチャー | 説明3分・2分（90秒＋交代）×4チーム×2巡＝16分・振り返り3分・予備3分 |
| 1:00〜1:25 | ③ 資源：インテリジェントなチームを作れ！ | 説明3分・8分×2ラウンド＝16分・集計と予備6分 |
| 1:25〜1:30 | 表彰 | 料理の点も足した合計で優勝発表 |

### ご飯企画（点数は合計に入る）

食材じゃんけん15分 → 料理40分 → 食べる40分 → 片付け10分（早く食べ終わったチームから）

## カードゲーム 1ラウンドの流れ（8分枠）

たくみさんの判断で変わる可能性あり。

1. **お題を引く（30秒）**
2. **山札を4つに分ける（30秒）**: 全員分のカードをシャッフルし、4チームに均等に配る
3. **チームで3人を選ぶ（2分）**: 手札だけから3枚を選び、チーム名を決める
4. **代表1人がプレゼン（45秒×4）**: 3枚をホワイトボードに貼り、選ばれた3人は前に立つ。代表はラウンドごとに交代
5. **投票（1分）**: 全員が自分のチーム以外に挙手で1票。相性ボーナスを加え、最多票のチームに得点

残り1分はカード回収と入れ替え。

## 妨害ジェスチャー（注意力）

テーマは「何に、いつ、どのように焦点を合わせるかが明確な状態」。

- 1チームずつ、演者1人が声を出さずにお題をジェスチャーで伝える。90秒で正解数がチームの得点。演者は毎回交代
- そのあいだ、ほかの3チームは妨害してよい（間違った答えを叫ぶ、手を振る、別のジェスチャーを見せる など）
- NG：演者や回答者に触る、視界を完全にふさぐ。目的は「散漫にする」こと
- フォーカスモード：演じるチームは自分の番に1回だけ宣言でき、20秒間ほかのチームは静かにする
- 振り返りで「フォーカスモードをいつ使った？なぜ？」を聞き、輪読につなげる

## 目的ズレ人狼

テーマは「目的の明確化と信頼」。カードは使わない。共通の課題に対し、1人だけ少し違う目的を配り、議論しながら誰がズレているかを当てる。

準備：
- 共通の課題（ゼミ合宿の企画、新入生歓迎会、架空サービスの立ち上げ など）
- 目的のペアを3〜4セット（「満足度を最大化」vs「コストを最小化」、「参加人数を増やす」vs「1人ひとりの体験を深める」、「話題性を出す」vs「失敗リスクを避ける」）
- 運営で読み合わせてズレの幅を調整（大きすぎるとすぐバレ、小さすぎると気づかれない）

## 相性ボーナス

- 各カードには、本人が書いた「🤝 相性◎：こんな人と一緒だとパフォーマンスが上がる」が載っている
- プレゼンで「AさんとBさんは相性◎、なぜならBさんは〇〇だから」と根拠を添えて主張する
- カードの本人が会場で「OK！」を出せば成立し、1つにつき＋2票
- 本人が不在のとき、または意見が割れたときは、たくみさんが最終判断する
- シナジー表のような覚えるルールは作らない
