# カードの仕様

## 判型と印刷

- 63×88mm（一般的なトレカと同じサイズ）
- 片面印刷で、裏面はなし
- A4普通紙に9枚（3×3）並べ、トンボ（切り取り線）を入れる
- 全員分を1セット＋予備1セット。30人分ならA4で約4枚×2

## 項目

上から順に並べる。見本はルール説明ページの「カードの見本」を参照。

| 項目 | JSONのキー | 文字数の目安 | 出どころ |
|---|---|---|---|
| カード名 | `name` | 12字 | フォーム1 |
| 役割 | `role` | — | フォーム3 |
| 絵 | `art` | — | 写真（フォーム11）。なければAIのイラスト |
| キャッチコピー | `catch` | 20字 | フォーム2（空欄ならAI） |
| タグ | `tags` | 最大3つ | フォーム4 |
| 強み | `strengths` | 各10字 × 2〜3個 | フォーム6 |
| 技の名前 | `move.name` | 12字 | フォーム7（空欄ならAI） |
| 技の効果 | `move.effect` | 40字 | フォーム7（空欄ならAI） |
| 🤝 相性◎ | `aisho` | 35字 | フォーム8 |
| 🙋 助けられること | `help` | 30字 | フォーム5 |
| 枠の色 | `color` | — | フォーム9 |

文字数の目安を超えるとカードからはみ出すので、AIに渡すプロンプトでも同じ上限をかけている。

## 絵

- 写真がある人は、写真をそのまま載せる（AIには渡さない）
- 写真がない人は、[`prompts/illustration.md`](../prompts/illustration.md) でイラストを生成する
- 生成が間に合わない場合は、タグに合った絵文字を大きく置いて代用する（ルール説明ページの見本と同じ見た目）
