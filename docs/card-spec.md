# カードの仕様

## 判型と印刷

- 63×88mm（一般的なトレカと同じサイズ）
- 裏面は顔写真（`art`）とカード名。Canvaの見本（`site/images/back/canva-original.png`）の柄を `site/card-back.js` でSVGに作り直し、柄×配色の組み合わせ（132通り）を並び順で割り当てるので全員ちがうデザインになる。一覧は `site/back.html`
- 印刷は `site/print.html` の2通り：表と裏を横に並べて真ん中で折る（A4横に4人分）か、両面印刷（表シートと左右を入れ替えた裏シート、A4縦に9人分）
- A4普通紙に9枚（3×3）並べ、トンボ（切り取り線）を入れる
- 全員分を1セット＋予備1セット。30人分ならA4で約4枚×2

## 項目

上から順に並べる。見本はルール説明ページの「カードの見本」、印刷レイアウトは `site/print.html` を参照。見た目はトレカ風（虹色のホロ枠、金の縁、名前と大きな絵、ラベル付きの情報欄、技の欄）。テンプレートは `site/card.css` と `site/card.js` で、画面表示と印刷で共用する。

| 項目 | JSONのキー | 文字数の目安 | 出どころ |
|---|---|---|---|
| カード名 | `name` | 12字 | フォーム1 |
| 役割 | `role` | — | フォーム3 |
| 絵 | `art` | — | 写真（フォーム11）。なければAIのイラスト |
| キャッチコピー | `catch` | 20字 | フォーム2（空欄ならAI） |
| タグ | `tags` | 最大3つ | フォーム4 |
| 強み | `strengths` | 各10字 × 2〜3個 | フォーム6 |
| 技（最大3つ） | `moves[].name` / `moves[].effect` / `moves[].tag` | 名前12字・効果30字 | フォーム7（足りない分はAI） |
| 相性◎ | `aisho` | 35字 | フォーム8 |
| 頼れる | `help` | 30字 | フォーム5 |
| 枠の色 | `color` | — | フォーム9 |

文字数の目安を超えるとカードからはみ出すので、AIに渡すプロンプトでも同じ上限をかけている。

### 技は3つ、分野をばらす

1つの分野に固定せず、その人のいろんな強みを知ってもらうのが目的。3つの技はできるだけ別々の強み・分野から作る（例：統計の技、デザインの技、趣味から来た技）。各技の左には分野のアイコンを付ける。

## 絵

- 写真がある人は、写真をそのまま載せる（AIには渡さない）
- 写真がない人は、[`prompts/illustration.md`](../prompts/illustration.md) でイラストを生成する
- 生成が間に合わない場合は、タグに合った絵文字を大きく置いて代用する（ルール説明ページの見本と同じ見た目）
